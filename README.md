# HospitalAsync (AsyncHealth)

A modern, responsive frontend application for healthcare and hospital management. Built to handle complex asynchronous operations seamlessly, providing an intuitive interface for medical staff and patients.

## 🚀 Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Library:** [React](https://react.dev/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Package Manager:** [pnpm](https://pnpm.io/)

## 📂 Project Structure

```text
.
├── app/               # Next.js App Router pages and layouts
├── assets/            # Static assets like images and global CSS
├── components/        # Reusable UI components (Navbar, buttons, etc.)
├── config/            # Global configuration files
├── data/              # Mock data or static data constants
├── hooks/             # Custom React hooks
├── lib/               # Utility functions and API helpers (Axios configurations)
├── providers/         # Context providers (e.g., Theme, Auth)
├── schemas/           # Zod validation schemas
├── stores/            # State management (Zustand/Redux)
└── types/             # TypeScript type definitions and interfaces
